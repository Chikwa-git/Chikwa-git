## Featured Projects

### Fundamenta
A financial health classifier for Brazilian public companies (B3), using Random Forest.
#### Main features
- Predicts company financial health with ~91% accuracy
- Interactive dashboard built with Flask
#### Technical highlights
- Feature engineering on real financial statement data
- Model evaluation and calibration techniques

### Nucleus
A multi-provider LLM document summarizer supporting OpenAI, Groq, and Gemini.
#### Main features
- Summarizes documents using multiple LLM providers
- Flexible provider switching
#### Technical highlights
- Built with Flask
- Clean abstraction layer across different LLM APIs

### DataComex
A foreign trade analysis tool powered by AI, built with Flask and the official Brazilian government API.
#### Main features
- Query export/import data by NCM code, year, and trade flow
- Top 10 destination/origin countries with FOB value
- Monthly trade evolution
- AI-generated insights using Groq (Llama 3.3 70B)
#### Technical highlights
- Integration with the **ComexStat public API** (Brazilian Ministry of Trade)
- AI analysis with contextual inference beyond raw data
- SQLite caching with 24-hour TTL
- Built with Flask, Jinja2, and Bootstrap 5

### Radar Político
A web application built as my **CS50X final project** to analyze public data from Brazilian federal deputies.
#### Main features
- Search for a specific deputy
- Show recent voting activity
- Display voting attendance percentage
- Show alignment percentage with the Chamber
- Identify top 5 most similar voting profiles
- Identify top 5 most different voting profiles
- Display the latest proposed bills
#### Technical highlights
- Integration with the official **Câmara dos Deputados Open Data API**
- Backend data processing and analysis with Python
- SQLite caching with 24-hour TTL to reduce repeated API calls
- Focus on handling real-world API limitations and performance issues

### Expenses Control

- Expense tracking
